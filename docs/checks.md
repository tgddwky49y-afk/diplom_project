# Проверки переноса

Проверено при подготовке версии:

- `dotnet build StudyPlanner.sln -m:1`: без ошибок и предупреждений.
- `npm ci` и `npm run build`: TypeScript и production-сборка React.
- 13 проверок в StudyPlanner.Checks: поля, допустимые значения, SQL Server-схема, ограничения и обнаружение миграции.
- HTTP: пустое название, неверный приоритет, прогресс 101 и неверная дата дают 400.
- Недоступная база даёт 503 в `/api/health`.
- EF Core сформировал идемпотентный SQL-скрипт миграции.

Полный тест сохранения в реальном SQL Server здесь не выполнялся: экземпляр базы отсутствует.
Для этой проверки предназначен `tests/api-smoke.mjs`. После запуска SQL Server, миграции и API выполните `node tests/api-smoke.mjs`.
До успешного прохождения этого теста нельзя считать интеграционную проверку базы завершённой.

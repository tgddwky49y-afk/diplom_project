# Учебный планировщик

Веб-приложение для учебных задач, сроков и прогресса.

## Что сделано на второй неделе

- подготовлена ER-диаграмма;
- добавлена миграция PostgreSQL;
- сервер подключён к базе данных;
- реализованы создание, просмотр, изменение и удаление задач;
- добавлена простая страница для работы с задачами.

## Запуск

1. Установить Node.js и PostgreSQL.
2. Создать базу данных `study_planner`.
3. Скопировать `.env.example` в `.env` и указать свои данные PostgreSQL.
4. Выполнить команды:

```bash
npm install
npm run db:migrate
npm start
```

5. Открыть в браузере `http://localhost:3000`.

## API задач

| Метод | Адрес | Действие |
|---|---|---|
| GET | `/api/tasks` | получить все задачи |
| GET | `/api/tasks/:id` | получить одну задачу |
| POST | `/api/tasks` | создать задачу |
| PATCH | `/api/tasks/:id` | изменить задачу |
| DELETE | `/api/tasks/:id` | удалить задачу |

Описание таблиц находится в файле `docs/database.md`.
